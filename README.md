
 🏦 Bank Loan & Credit Risk Analytics

📌 Project Overview
This project analyzes banking loan application data to identify
customer risk patterns and understand factors associated with
loan repayment difficulties.
The analysis combines current loan application data with
previous loan history to build a stronger customer-level risk view.

🎯 Objectives
- Analyze loan applicant characteristics
- Identify higher-risk customer segments
- Study income and education-related risk patterns
- Analyze previous loan behaviour
- Compare approved and refused applications
- Calculate customer-level approval rates
- Generate actionable business recommendations

📂 Datasets
The project uses three datasets:

- `application_data.csv` — Current loan applications
- `previous_application.csv` — Previous loan application history
- `columns_description.csv` — Column definitions
  
🛠️ Tools & Technologies
- 🐍 Python
- 📊 Pandas
- 📈 Matplotlib
- 📓 Kaggle Notebook
- 📁 CSV Dataset

🔍 Analysis Performed
1. Data Cleaning
- Checked duplicate records
- Identified missing values
- Removed columns with excessive missing data
- Created a cleaned application dataset
 2. Exploratory Data Analysis
- Analyzed customer demographics
- Studied income and employment characteristics
- Examined credit and annuity amounts
- Compared `TARGET` risk groups
3. Previous Loan Analysis
- Analyzed previous loan statuses
- Calculated previous loan counts
- Compared approved and refused applications
- Calculated customer approval rates
- Analyzed average previous credit
 4. Risk Visualization
The project includes visualizations for:

- 📊 Loan Risk Distribution
- 🎓 Risk Rate by Education
- 💼 Risk Rate by Income Type
- 🏦 Previous Loan Status

💡 Key Business Insights
1. Loan repayment risk varies across customer segments.
2. Education categories show differences in observed risk rates.
3. Income type is associated with different levels of repayment risk.
4. Previous loan behaviour provides valuable information for understanding customer credit history.
5. Previous loan count and approval rate can help segment customers.
6. Combining current application information with previous loan
   history provides a stronger customer risk profile.

🚀 Business Recommendations
- Use risk-based loan assessment.
- Include previous loan behaviour in credit evaluation.
- Perform additional verification for higher-risk applicants.
- Consider income stability during credit assessment.
- Segment customers based on their credit history.
- Develop a customer-level risk scoring system.
  
🎯 Key Takeaway
A multi-factor credit risk approach can help financial institutions
make more consistent lending decisions, identify higher-risk
customers, and improve monitoring of loan portfolios.
